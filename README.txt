3D FOOTBALL — ONLINE 1 НА 1

ФАЙЛЫ
- index.html — сама игра
- server.js — сервер комнат и обмена данными
- package.json — зависимости Node.js

ЗАПУСК НА КОМПЬЮТЕРЕ
1. Установи Node.js 18 или новее.
2. Открой терминал в папке с этими файлами.
3. Выполни: npm install
4. Выполни: npm start
5. Открой http://localhost:3000 в браузере.

ИГРА С ДРУГОГО ТЕЛЕФОНА ЧЕРЕЗ ИНТЕРНЕТ
Сервер должен быть размещён на публичном Node.js-хостинге (например, Render).
Загрузи все три файла в один GitHub-репозиторий и создай Web Service:
- Build Command: npm install
- Start Command: npm start
После публикации открой HTTPS-адрес сервиса. Оба игрока должны заходить именно по этому адресу.

КАК ИГРАТЬ
1. Первый игрок нажимает «ОНЛАЙН 1 НА 1» → «СОЗДАТЬ КОМНАТУ».
2. Он отправляет шестизначный код второму игроку.
3. Второй игрок открывает тот же адрес игры, вводит код и нажимает «ПРИСОЕДИНИТЬСЯ».
4. Первый игрок нажимает «НАЧАТЬ МАТЧ».
5. Создатель комнаты играет за синих, подключившийся — за красных.
6. У каждого свой SWITCH, джойстик, пас, удар, отбор и бег. Остальные футболисты управляются ботами.

ВАЖНО
Это первая сетевая версия: игровую симуляцию выполняет телефон создателя комнаты, а второй телефон получает синхронизированные состояния и отправляет управление. Поэтому создателю комнаты желательно иметь стабильное соединение. Для реальной игры через интернет нужен публичный сервер; просто переслать HTML-файл недостаточно.
